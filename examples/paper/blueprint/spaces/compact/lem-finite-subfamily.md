For $J \subseteq I$ finite, $(U_j)_{j \in J}$ covers $X$ if and only if
$\bigcap_{j \in J} F_j = \emptyset$.  Hence $(U_i)$ has no finite subcover
if and only if $(F_i)$ has the finite intersection property.
